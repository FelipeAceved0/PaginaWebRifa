# Plataforma de Rifa Online (Prototipo UI/UX)

Este es un prototipo visual interactivo (MVP) para una plataforma web de venta de números de rifa. El diseño está enfocado en transmitir confianza, profesionalismo y una estética de e-commerce real.

Actualmente, el proyecto funciona con **datos simulados (mock)** y está preparado arquitectónicamente para integrar posteriormente un backend real, base de datos y pasarela de pago (Mercado Pago).

## Características principales

* **Diseño Editorial & Premium:** Interfaces limpias, espaciosas y alejadas del aspecto de "plantilla genérica".
* **Flujo de Checkout (Mock):** Selección interactiva de números y flujo visual de compra.
* **Panel de Administración (Responsive):** Dashboard para visualizar ventas, recaudación y estado de los números. Todo 100% responsivo y en español.
* **Optimización Móvil Real:** Sin scrolls horizontales accidentales, tablas adaptables y menús específicos para móviles (drawer).

## 🚀 Cómo probar y ver la página localmente

Sigue estos pasos para levantar el entorno de desarrollo y probar el prototipo en tu computadora:

### 1. Requisitos Previos
Asegúrate de tener instalado en tu computadora:
* [Node.js](https://nodejs.org/es/) (Se recomienda la versión LTS)
* [Git](https://git-scm.com/)

### 2. Clonar el Repositorio
Abre tu terminal y clona este repositorio en tu computadora:
```bash
git clone https://github.com/FelipeAceved0/PaginaWebRifa.git
cd PaginaWebRifa
```

### 3. Instalar Dependencias
Dentro de la carpeta del proyecto, instala todas las dependencias necesarias de React y Vite ejecutando:
```bash
npm install
```

### 4. Iniciar el Servidor de Desarrollo
Una vez instaladas las dependencias, levanta la aplicación con:
```bash
npm run dev
```

### 5. Ver en el Navegador
La terminal te mostrará una dirección local (por lo general es `http://localhost:5173/`).
* Abre tu navegador (Chrome, Firefox, Safari).
* Ve a `http://localhost:5173/` para visualizar la plataforma.

---

## 🛠️ Rutas disponibles para explorar
* `/` -> Página principal (Hero, premios y selección de tickets).
* `/checkout` -> Pantalla de resumen de compra y formulario de usuario (Mock).
* `/admin` -> Panel de administración para ver estadísticas de ventas (Mock).

## 💻 Tecnologías Utilizadas
* **React + TypeScript:** Lógica de la aplicación y tipado estricto.
* **Vite:** Empaquetador extremadamente rápido.
* **Lucide React:** Sistema de iconos ligeros y escalables.
* **React Router:** Enrutamiento del lado del cliente.
* **Vanilla CSS:** Hojas de estilo personalizadas con un sistema visual sólido.
